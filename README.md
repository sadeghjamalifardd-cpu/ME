# دفتر من

دفتر شخصی: ساعت کاری، خرید اعتباری، حقوق، مدیریت مالی، برنامه و آلارم.
نصب‌پذیر (PWA)، آفلاین، با قفل رمز و ورود با اثر انگشت.

## انتشار روی گیت‌هاب
1. یک repo جدید بسازید و همه‌ی فایل‌های این پوشه را آپلود کنید (شاخه‌ی `main`).
2. Settings ← Pages ← Source را روی **GitHub Actions** بگذارید.
3. بعد از چند دقیقه آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.

## نصب روی گوشی
آدرس بالا را در Chrome (اندروید) یا Safari (آیفون) باز کنید ← «افزودن به صفحه‌ی اصلی / Install».

## اثر انگشت
تنظیمات ← «قفل با رمز» را فعال کنید ← «فعال‌سازی اثر انگشت». رمز همیشه به‌عنوان جایگزین باقی می‌ماند.
اثر انگشت فقط روی HTTPS (مثل GitHub Pages) کار می‌کند، نه با باز کردن مستقیم فایل.

## داده‌ها
همه‌ی اطلاعات فقط در مرورگر همین دستگاه ذخیره می‌شود. از «خروجی JSON» مرتب پشتیبان بگیرید.
